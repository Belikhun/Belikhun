This repository is that site: one long page read by scrolling, built with Bun, SvelteKit, SCSS, GSAP and Lenis, and hosted on my own harbor.

## Running it

```
bun install
bun run dev        # dev server on :8500
bun run check      # svelte-check
bun run build      # static site in build/
bun run banner     # redraw the banner above from the site's hero (needs Python + Pillow)
```
